# Backend Engineering

**4 benchmark tasks**

This domain targets production-style backend reliability, asynchronous execution, service recovery and Nginx operations.

| Task | Difficulty | Focus |
|---|---|---|
| `backend-async-job-recovery` | Hard | Durable job claiming, lease recovery, idempotent effects |
| `backend-production-recovery` | Hard | systemd, Gunicorn/Uvicorn, Unix sockets, Nginx |
| `backend-service-recovery` | Hard | Service lifecycle, socket routing, restart resilience |
| `nginx-request-logging` | Medium | Nginx install/configuration, logging, rate limiting |

## Evaluation themes

The verifier focuses on durable state, service lifecycle, race conditions, API preservation, reverse-proxy behavior and restart recovery.
