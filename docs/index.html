What we build

The benchmark is designed to measure whether an AI coding agent can understand a system, identify the underlying failure, make a coherent repair, preserve unrelated behavior, and pass independent verification.

Core principle: the agent should solve the engineering problem — not discover the test.

How evaluation works

Tasks use isolated Docker environments, reference solutions, public and hidden tests, and independent verification. Many tasks also include anti-shortcut constraints such as workload preservation, immutable artifacts, cross-resource invariants, and rejection of destructive recovery strategies.

About the work

Forge Bench is an independent benchmark portfolio created by Mohamed Ahmed. The work combines benchmark engineering, Dockerized task environments, deterministic verifiers, reference solutions and anti-leakage/anti-shortcut design for AI coding-agent evaluation.
